# BEKIUZ Usta

Uy qurish va ta'mirlash uchun brauzerda ishlaydigan dastlabki hisob-kitob yordamchisi.

## Hozirgi imkoniyatlar

- Uy uzunligi, eni, qavatlar soni, devor balandligi va qalinligini kiritish.
- Umumiy pol maydoni, tashqi devor perimetri, devor yuzasi va hajmini hisoblash.
- Eshik va derazalar egallagan maydonni devor yuzasidan ayirish.
- Maydon asosida taxminiy budjetni hisoblash.
- Materiallar bo‘limida g‘isht miqdori, zaxira foizi, dona narxi va umumiy qiymatni hisoblash.
- Hisob natijalarini nusxalash.
- Mobil ekranlarga mos interfeys.

## Ishga tushirish

Bu statik web-app. `index.html` faylini brauzerda ochish yoki GitHub Pages orqali joylashtirish mumkin. Build vositasi yoki API kaliti talab qilinmaydi.

## Hisob-kitob chegaralari

Natijalar dastlabki taxmin uchun. Ichki devorlar, poydevor, armatura, ustun/to‘sin, tom konstruksiyasi, mahalliy material o‘lchamlari va haqiqiy bozor narxlari to‘liq hisoblanmaydi. Eshik-deraza maydoni qo‘lda kiritiladi. Bu hisoblar professional smeta yoki muhandislik loyihasi o‘rnini bosmaydi.

## Keyingi bosqich

- Xonalar bo‘yicha alohida reja va ichki devorlar.
- Materiallar ro‘yxatini kengaytirish va hududiy narxlarni yangilash.
- Loyihalarni saqlash va qayta ochish.
- Konseptual 2D/3D ko‘rinish.
